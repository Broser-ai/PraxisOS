# Omnichannel Swarm · Architecture

## Brands (tenants)

| Brand | CRM | Voice | Engage |
|---|---|---|---|
| Praxios | crm.praxios.dk | voice.praxios.dk | engage.praxios.dk |
| Cirkel | crm.cirkel.dk | voice.cirkel.dk | engage.cirkel.dk |
| DPN nails | crm.dpnnails.dk | voice.dpnnails.dk | engage.dpnnails.dk |

Routing is **Host/SNI via Traefik** on shared Docker network `omni_net`.

## Stack

```
                    ┌─────────────────────┐
   :80/:443         │  Traefik gateway    │  Let's Encrypt (TLS-ALPN)
───────────────────►│  traefik_gateway    │
                    └─────────┬───────────┘
                              │ omni_net
        ┌─────────────────────┼─────────────────────┐
        ▼                     ▼                     ▼
   Erxes (CRM)          Fonoster (Voice)      Dittofeed (Engage)
   Mongo/PG/Redis       Routr/Asterisk/       PG/ClickHouse/
                        RTPEngine/API         Temporal
```

## Data-flows

### 1. Omnichannel inbox (Erxes)
Browser → Traefik (`crm.*`) → `erxes-gateway` → Mongo (docs) + Postgres + Redis.

### 2. Zero-cost voice (Fonoster)
Browser/SDK → Traefik (`voice.*`) → Fonoster dashboard/API.  
Signaling/media: WebRTC/SIP over data (Routr + RTPEngine).  
**PSTN/Twilio env vars stay empty** unless explicitly enabled as fallback.

### 3. Marketing (Dittofeed)
Browser → Traefik (`engage.*`) → `dittofeed-lite` → Postgres + ClickHouse + Temporal.  
Channels: web-push, email, Telegram first; SMS optional.

## Security

- Secrets only in per-stack `.env` (gitignored)
- Fonoster RSA keys generated by `make init-keys` (not committed)
- Traefik dashboard behind basic auth
- No hardcoded credentials in compose files

## Ops

```bash
make init          # network + env skeletons + keys
# edit all .env files
make deploy-all

```
